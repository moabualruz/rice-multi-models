# 0.9 verification

The 0.9 releases run only through public plugin hooks in the ordinary `claude` command. It
registers no MCP tools and ships no launcher, preload, proxy or gateway; the
withdrawn 0.8.0 adapter bundles are removed.

## Canonical gate

`bun run check` passed on macOS with Claude Code 2.1.302 on the 0.9 tree, and the hosted job passed on the release commit (8bbd0b8 for 0.9.1) for Linux (Claude Code 2.1.301 and 2.1.302) and native Windows (2.1.302):

| Check | Result |
| --- | --- |
| Unit and integration suites (`bun run test`) | 489 tests pass |
| Helper typecheck, bundle check | pass; bundle current |
| Hooks typecheck against the installed build's own declarations | pass, no inference |
| Node runtime tests | 32 pass |
| Clean shipped payload (`test:install`) | pass: no Bun, curl, jq or node_modules |
| Lifecycle fixtures through `claude plugin test` | 3 pass |
| Routing (`test:routing`) | 500k native window; auxiliary calls routed, no native completions |
| Routing phases (`test:phases`) | children (with and without session persistence), family, built-in tools, compaction, classifier, skills, budget, partial failure, prompt evaluators, five protocols, automatic compaction and a throwing `turn.step` hook: pass, no request reached the refusing Anthropic endpoint |
| Compaction | manual and automatic compaction saved and resumed through the selected provider |
| Permissions and permission mode | 7 and 4 cases; no native inference |
| Web search and fetch | provider search, configured services, native fallback and provider extraction |
| Evaluators | prompt evaluators routed, agent-type evaluators native, hidden sources native |
| Titles | 4 cases; no native naming requests |

The proofs use local stand-in providers and an Anthropic endpoint that refuses
every request; they establish routing and lifecycle behavior, not live provider
entitlement or quota. GitHub Actions runs the same gate on Linux for Claude Code
2.1.301 and 2.1.302 and on native Windows for 2.1.302.
